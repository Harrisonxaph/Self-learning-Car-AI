      Training checkpoint

      A checkpoint is this run at a generation boundary, so it can be resumed later. It is saved in this browser only, which is a convenience, not a backup: Download checkpoint keeps a copy as a file. A saved checkpoint is only ever offered; nothing resumes by itself.

      Saved champions
